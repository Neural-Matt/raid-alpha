One-time setup: Google Cloud Console → enable Gmail API → OAuth Web application client → set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET and GOOGLE_REDIRECT_URI as environment variables wherever the app runs, then click Connect Gmail. Full steps are in the README.

Checking…

One-time setup: developers.facebook.com → create a Meta App → add the "WhatsApp" product → API Setup gives you the Phone Number ID; generate a permanent token under Business Settings → System Users. Full steps and the 24-hour messaging-window policy are in the README.
